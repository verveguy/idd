Character Builder

Building a legal character means juggling heritages, factions, headers, prerequisites, spheres and a strict CP budget. These tools do the bookkeeping — so you can think about who your character is, not whether the maths adds up.

Unofficial · fan-made · free

The web builder

A point-and-click character sheet that tallies as you go. Open it in any browser — phone, tablet or laptop.

  • The whole ruleset built in — 6 heritages, 4 factions, 27 headers, 49 spells
  • Live CP ledger and Vitality, updating with every choice
  • Catches illegal builds — missing prerequisites, faction-locked headers, mutually exclusive skills, overspending
  • Sign in to save a private library of characters, synced across your devices
  • Printable sheet, and a share link that opens your exact build

Claude Desktop

Build it with Claude

Describe the character you want in plain English and let Claude assemble a legal build with you, explaining the trade-offs as it goes.

  • Say “a Grelkyn storm-mage who dual-wields” — Claude finds the headers, skills and spells that fit
  • Watch it happen live — a browser page fills in as Claude makes each choice
  • Every step is rules-checked, so it can’t hand you an illegal character
  • Knows where everything lives — which faction unlocks a header, which sphere holds a spell
  • Saves characters on your machine to revisit and level up later
  1. Download the extension below.
  2. Open it — Claude Desktop installs it (or use Settings → Extensions).
  3. Restart Claude Desktop, then just ask it to build a character.

Which one should I use?

Use the web builder if you know roughly what you want and would rather click through it yourself — it’s the fastest way to sketch a character, and the only one that works on a phone at the table.

Use the Claude extension if you’re starting from a concept rather than a stat line, or you’re new to the system and want the trade-offs explained as you go. It’s also the better tool for “can I make this work?” questions.

They fit together: build with Claude, then open the same character in the web builder to print a sheet — copy the build JSON out of the conversation and paste it into Import JSON.

What the tools know

Everything is checked against the published In Darkened Dreams ruleset (v1.0.3), including the CP cost curve, Vitality, faction gating, prerequisites and mutual exclusions.
